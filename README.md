# Barbería Calviño

Sitio web multipágina para una barbería especializada en cabello largo.

## Estructura

- `index.html` — Inicio
- `servicios.html` — Catálogo de servicios
- `contacto.html` — Formulario de contacto

## Framework

Tailwind CSS v4 (Play CDN). Se eligió por su enfoque utility-first,
sistema responsive con prefijos y rapidez de implementación.
